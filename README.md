# Tic Tac Toe Game 🎮

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## 🌐 Live Demo

https://korupuripallavi.github.io/tic-tac-toe/

## 📌 About the Project

This is a browser-based Tic Tac Toe game for two players.

Players take turns placing X and O on a 3 × 3 game board. The game automatically checks for a winner or a draw and provides an option to restart the game.

## ✨ Features

- Two-player gameplay
- Player X and Player O turns
- Automatic winner detection
- Automatic draw detection
- Restart game button
- Interactive 3 × 3 game board
- Responsive design
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
